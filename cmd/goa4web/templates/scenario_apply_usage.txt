Usage:
  {{.Prog}} scenario apply <path> [<path>...]

Validates, preflights, and applies a scenario TXTAR file or directory to the configured
database using standard application domain operations.

Supported discussion operations include forum.thread.create and forum.reply. They use
symbolic topic/thread references and event bodies, and follow the same permission and
side-effect boundary as normal HTTP forum actions. Image attachment ingestion remains
unsupported.

Arguments:
  <path>    Path to a .txtar scenario file or scenario directory. Multiple paths are
            applied in command-line order with shared symbolic references.

Examples:
  # Apply a scenario TXTAR file
  {{.Prog}} scenario apply testdata/scenarios/100-private-forum/scenario.txtar

  # Apply a directory containing scenario.txtar and assets/
  {{.Prog}} scenario apply testdata/scenarios/100-private-forum

  # Compose ordered scenario directories
  {{.Prog}} scenario apply testdata/scenarios/000-base-users testdata/scenarios/100-private-forum
