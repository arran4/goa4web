Usage:
  {{.Prog}} scenario <command> [<args>]

The scenario command provides tools for validating and executing human-readable
application event scenarios.

Scenarios use semantic operations such as user.create, private-forum.create,
forum.thread.create, and forum.reply. The event body supplies thread and reply text;
symbolic Ref, Actor, Topic, and Thread fields keep fixtures independent of database IDs.

Commands:
  apply       Apply a scenario file or directory to the database.
  serve       Serve a disposable SQLite environment created from a scenario.
  validate    Validate a scenario file or directory.

Examples:
  # Apply a scenario to the database
  {{.Prog}} scenario apply testdata/scenarios/100-private-forum/scenario.txtar

  # Validate a scenario TXTAR file
  {{.Prog}} scenario validate testdata/scenarios/100-private-forum/scenario.txtar

  # Validate a scenario directory containing scenario.txtar
  {{.Prog}} scenario validate testdata/scenarios/100-private-forum

The representative 100-private-forum scenario creates four loginable users, three
private conversations with overlapping membership, and real threads and replies.
Thread creation may include repeated Asset headers pointing to adjacent image files.
Assets are validated and imported through the normal image upload pipeline.
