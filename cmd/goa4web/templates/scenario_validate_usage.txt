Usage:
  {{.Prog}} scenario validate <path>

Validates that a scenario TXTAR file or directory conforms to the format
specification, has valid timestamps and references, and that all adjacent
asset files exist without directory traversal escapes.

Arguments:
  <path>    Path to a .txtar scenario file or scenario directory.

Examples:
  # Validate a scenario TXTAR file
  {{.Prog}} scenario validate testdata/scenarios/100-private-forum/scenario.txtar

  # Validate a directory containing scenario.txtar and assets/
  {{.Prog}} scenario validate testdata/scenarios/100-private-forum
